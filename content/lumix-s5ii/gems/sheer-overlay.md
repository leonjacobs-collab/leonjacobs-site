`[Sheer Overlay]` lets you overlay a previously taken photo (or a frame extracted from a video) onto your live view with adjustable transparency [^manual]. The overlay sits on top of what you're currently framing — both visible at the same time.

**Use cases that aren't obvious from the menu name:**

- Match a composition exactly for before/after shots
- Recreate a reference image or storyboard frame
- Align elements for double-exposure compositions
- Match angles across multiple shooting days for time-lapse continuity

You can set it to disappear when you half-press the shutter via `[Disp. Image (shutter-press)]` set to `[OFF]`, so it doesn't distract during actual capture [^manual].
